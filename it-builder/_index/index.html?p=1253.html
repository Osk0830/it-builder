活用例

エントリーシート管理

企業の採用活動におけるエントリーシートを、応募者がWeb上で作成することができるアプリです。
採用担当は、エントリーの受け付け、シートの形式審査などの処理を行い、結果をステータスとして一覧形式で管理できます。

サンプルアプリダウンロード

※ご利用者さま専用サポートサイトを表示します
アプリのダウンロードにはログインが必要です。

Web上でシート作成と
エントリーが可能

応募者はWeb上でエントリーシートを作成し、エントリー申し込みすることができます。
シートは作成途中で一時保存することも可能なため、できあがったシートをよく確認してからエントリーすることができます。

エントリーシートは
データベースに保存

応募者によってエントリーシートに入力された情報は、そのままイットbuilderデータベースに保存されるため、企業の採用担当は、従来のように書面で受け取ったエントリーシートを転記入力してデータを作成する必要がありません。
また、採用関係者間でエントリー情報を共有することも、紙面の場合に比べ、極めて容易になります。

データへの
アクセス制御で機密を保護

応募者には個別にエントリー用のログインIDが付与されるため、作成したエントリーシートの閲覧、修正などは本人のみ可能です。
企業側も、エントリー受付業務に携わる特定の採用担当者だけがエントリー情報にアクセスできますので、機微なエントリーデータを厳重に守ることができます。
