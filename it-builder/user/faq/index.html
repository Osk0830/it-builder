よくある質問 絞り込み条件

  • アプリ作成の容易性

    プログラミングに関する知識がなくても、簡単にWebアプリを作成できるというのは本当ですか？

    プログラミングやHTMLに関する専門知識は一切不要です。簡単なマウス操作とキーボード入力だけでWebアプリが完成します。

  • 既存システムのユーザーマスター利用

    社内のグループウェアと同じID、パスワードでイットbuilderにログインすることができますか？

    イットbuilderには、LDAPに準拠した認証基盤と連携する機能があります。
    お客さまがご利用のグループウェアがLDAP認証基盤を使用するものであれば、社内のグループウェアと同じID、パスワードでイットbuilderにログインすることができます。

  • シングルサインオン

    シングルサインオンは可能ですか？

    イットbuilderは、ADFS（Active Directoryフェデレーションサービス）に対応していますので、シングルサインオンでイットbuilderへのアクセスが可能です。システムごとにID/パスワードを使い分ける必要がありません。

  • IPアドレスによるログイン制限

    使用するパソコンのIPアドレスによって、ログイン制限することはできますか？

    イットbuilderでは、特定のIPアドレス以外の端末はイットbuilderにアクセス（ログイン）できないよう、アプリごとに制限することができます。
    この機能を利用すれば、アンケートアプリは社外の不特定多数の方も使用できるようにし、社員だけが使用するアプリはIPアドレス制限で社外第三者の使用をブロックする、などの制御が可能です。

  • スマートフォンにおけるアプリ動作

    作成したアプリを、スマートフォンで使用することができますか？

    もちろんできます。
    Webブラウザが動作する機器であれば、種類を問わず使用可能です。

  • スマートフォン画面の表示最適化

    パソコンで作成したアプリをスマートフォンで使用する場合、画面が見にくくなりませんか？

    イットbuilderはレスポンシブデザインに対応していますので、パソコンやスマートフォンそれぞれに適した、見やすい画面表示に自動調整されます。

  • 複数画面で構成されるアプリの作成

    複数画面に展開するアプリを作ることができますか？

    たとえば、「ログイン画面」→「データ一覧画面」→「1件のデータ表示画面」と遷移するアプリを作成することができます。

  • ログインユーザーによる条件分岐

    ユーザーマスターの役職コードなどによって、表示する画面や項目を変更することができますか？

    条件分岐部品を利用すれば、ログイン者の役職コードによって表示する画面や項目を制御することが可能です。

  • 入力値による条件分岐

    画面入力された値によって、異なる処理を行うことができますか？

    条件分岐部品を利用すれば、画面入力された値によって表示する画面や項目を制御することが可能です。

  • テーブル、項目の作成上限数

    作成するデータベースの、テーブル数や項目数に制限はありますか？

    データベース1グループで200テーブルまで、1テーブルには200項目まで作成可能です。

  • 帳票出力

    帳票出力機能はありますか？

    イットbuilderは、PDFまたはExcel形式でデータを出力することができます。
    Excel出力機能を利用すれば、一覧表、単票や1対N形式の見積書など、さまざまな帳票を簡単に作成することができます。

  • データベースのインポート／エクスポート

    イットbuilderデータベースにデータをインポートしたり、エクスポートしたりすることは可能ですか？

    アプリ作成画面で、イットbuilderデータベースへのCSVデータのインポートやエクスポートの操作が可能です。
    また、作成するアプリに、CSV形式でのデータ出力機能を組み込むこともできます。

  • バッチ処理の自動実行

    指定した日時に、バッチ処理を自動的に実行することができますか？

    可能です。
    イットbuilderで作成したバッチ処理アプリは、日時を指定するほか、毎月または毎週の指定曜日など、一定間隔で自動実行することができます。

  • プルダウン項目の絞り込み

    択一選択プルダウンで、選択候補が多い場合にマウス操作で対象のものを探すのが面倒なのですが、何かよい方法はありませんか？

    択一選択プルダウンには、検索オプションがあります。
    これを利用することで、選択対象の文字列の一部を指定し、選択候補を絞り込むことができます。

  • 画面選択値による入力項目初期値の自動設定

    商品名をプルダウンから選択すると、型番、単価などのデータが自動的に入力されるようなアプリを作成できますか？

    イットbuilderには、プルダウンなどで選択された項目を検索キーとして所定のデータを検索し、入力項目の初期値として表示する、自動入力機能があります。
    これを利用することで可能です。

  • 郵便番号による住所検索

    郵便番号から住所を取得する機能はありますか？

    イットbuilderは、郵便番号を住所に変換するためのデータベースを備えています。
    このデータベースは、日本郵便ホームページに公開されている郵便番号と住所の対応データが毎月自動的に取り込まれ、最新化されます。

  • 複数データベースの1画面表示

    複数のデータベースの情報を1画面に表示できますか？

    イットbuilderでは「1対N形式データ表示」が可能です。
    通常、1画面には1つのデータベースのデータを表示するのに対し、「1対N形式データ表示」では、あるデータベースの1件のデータとともに、これに関連する他のデータベースの複数件（N件）のデータを1画面に表示するものです。
    たとえば、従業員台帳アプリにおいて、ある従業員の氏名、入社年月日などの従業員マスタの情報（1件）とともに、この従業員が保有する複数（N件）の資格情報を資格マスタから抽出して1画面に表示するなどのアプリを作成することができます。

  • イットbuilderと基幹システムとの間のデータ相互更新

    基幹システムとリアルタイムにデータ連携できますか？

    基幹システムのデータベースに対してイットbuilderアプリからリアルタイムにデータ操作を行いたい場合は、基幹システム側にWebAPIが用意されていれば、それをイットbuilderが呼び出すことで実現できます。
    逆に、基幹システムからイットbuilderデータベースへのリアルタイム連携は、イットbuilderデータベースの登録、検索、更新、削除が可能なAPIを、基幹システムが呼び出すことにより実現できます。

  • 基幹システムのデータ取り込み

    基幹システムからの出力データを、イットbuilderに取り込むことはできますか？

    基幹システムのデータをCSV形式で出力すれば、イットbuilderデータベースに取り込むことができます。
    取り込みは、アプリ作成画面で操作するか、バッチアプリを作成することにより可能です。

  • アプリ画面デザインのカスタマイズ

    アプリ画面のデザインを、標準的なもの以外に変更できますか？

    HTML、CSS、JavaScriptなどを使用して、画面デザインを自由に変更することができます。

  • アプリによるデータ更新の履歴

    データの更新履歴を確認できますか？

    イットbuilderでは、データレコードごとに更新者や更新日時などの履歴情報が自動記録されていますので、これによって確認することができます。
    記録される情報は、登録者（ログインID）、登録日時、最終更新者（ログインID）、最終更新日時です。

  • アプリの使用履歴

    作成したアプリの使用履歴を確認できますか？

    イットbuilderでは、アクセスログにアプリ実行履歴情報が自動記録されています。
    記録される情報は、いつ、誰（ログインID）が、どのアプリを実行したか、どのデータベースの、どのレコードを更新したか、誰にどんな内容のメールを配信したか、どのPDF帳票を出力したか、などです。

  • 作成したアプリを利用可能にする方法

    作成が終わったアプリを使えるようにするには、どのような操作をすればよいですか？

    アプリ作成画面のスライドボタンを、「アプリ稼働中」に設定するだけで使用可能な状態になります。コンパイルなどの特別な操作は必要ありません。

  • 項目計算式の設定

    項目に計算式を設定することはできますか？

    数値項目の四則演算、文字列項目からの指定桁数の文字列取り出しほかの関数を利用することができます。

  • ユーザー数無制限とは

    「ユーザー数無制限」とのことですが、ユーザーとは何のことですか？

    ユーザーとは、イットbuilderを利用してアプリを作成する人、およびそのアプリを使用する人のことをいい、ご契約企業の方であれば人数に制限なくご利用いただけます。

  • 複数サーバ環境の必要ライセンス

    複数のサーバ構成でイットbuilderを使用する場合には、サーバー台数分のライセンスが必要ですか？

    アプリケーションサーバの台数にかかわらず、1ライセンスで1データベースをお使いいただくことができます。
    アプリケーションサーバが2台以上の構成であってもデータベースがひとつなら、1ライセンスのご契約で問題ありません。

  • クラウドプランの最低利用期間

    クラウドプランを、3か月間だけ利用することはできますか？

    クラウドプランは、最低ご利用期間を6ヵ月とさせていただいております。

  • 保守サービス内容

    保守サービスの内容を教えてください。

    専用フォームによるお問い合わせの受付とご回答、バージョンアップが実施された際の最新版の無償でのご提供などです。

  • 無料トライアルと製品版の違い

    「180日間無料トライアル」で試すことができるイットbuilderは、製品版とどのような違いがあるのですか？

    製品版（ただし、システム管理者機能は除く）と全く同じ機能を、最長180日間にわたってお試しいただけます。
    試用期間中に作成したアプリやデータは、ご契約いただいた後も、すべてそのままご利用になれます。

  • 契約者以外によるアプリ使用

    作成したアプリを、お客さまにご利用いただいても構いませんか？

    イットbuilderでアプリを作成し、これをお使いいただけるのは、原則としてご契約者（法人を含みます）のみです。 ただし、お客さまの意見を収集するアンケートやお客さまからの申込みを受け付けるアプリなど、ご契約者ご自身（自社）の業務遂行のために、お客さまにアプリをご利用いただく必要がある場合には、例外的にこれを認めます。
    したがって、アプリを提供すること自体を、事業あるいはサービスとしてお客さまに提供することはできません。

  • 契約者以外によるアプリ作成

    契約者（契約企業）以外がアプリ作成をすることはできますか？

    アプリを作成することができるのは、ご契約者のみです。
    ただし、業務委託や派遣などの契約に基づいて、他者（企業を含みます）にアプリ作成を依頼される場合には、ご契約者自身による作成とみなし、これを認めます。

  • グループ会社のアプリ使用

    当社がアプリを作成し、これをグループ会社に使ってもらうことでサービス利用料を徴収するというビジネスを始めたいのですが、問題はありますか？

    イットbuilderでアプリを作成し、これをお使いいただけるのは、原則としてご契約企業のみです。 ただし、御社のグループ会社のうち親会社および子会社に限っては、有償であるか否かを問わず、御社が作成したアプリをお使いいただくことができます。
    この場合でも、関連会社にはお使いいただくことができず、アプリの作成は御社のみ可能である点にご注意ください。ご不明な点は弊社にお問い合わせください。

  • お客さま調達のAWS環境におけるご利用

    当社は現在AWSを利用しているのですが、この環境にイットbuilderを導入して使うことはできますか？

    クラウドプランは、サービス品質の保証のため、弊社がご用意するAWS環境をお使いいただける場合に限ってご提供しております。

  • アプリ作成画面の動作不良

    イットbuilderのアプリ作成画面が動作しなくなりました。どうすればよいですか？

    下記操作により、キャッシュをクリアすると復旧します。

    ◇Microsoft Internet Explorer11の場合
    「インターネットオプション」→「全般」タブ→「閲覧の履歴」の「削除」ボタンをクリック

    ◇Google Chromeの場合
    「設定」を開く → 「詳細設定を表示...」をクリック → 「プライバシー」 → 「閲覧履歴データの消去」ボタンをクリック → 「キャッシュされた画像とファイル」にチェックを入れる → 「閲覧履歴データを消去する」ボタンをクリック

  • CSVダウンロード時のファイル名の文字化け

    ダウンロードしたCSVファイルのファイル名が文字化けします。どうすればよいですか？

    UTF-8に対応した解凍ツールをご利用ください。

    Windows7標準のエクスプローラで閲覧する際に文字化けする場合は、
    以下のURLより修正プログラムをダウンロードして、Windows Updateを実施してください。

    ・32bit版
    http://hotfixv4.microsoft.com/Windows%207/Windows%20Server2008%20R2%20SP1/sp2/Fix387976/7600/free/448094_intl_i386_zip.exe

    ・64bit版
    http://hotfixv4.microsoft.com/Windows%207/Windows%20Server2008%20R2%20SP1/sp2/Fix387976/7600/free/448095_intl_x64_zip.exe

  • ファイルアップロード時のエラー

    Microsoft Internet Explorer利用時に、ファイルアップロードでエラーが発生します。どうすればよいですか？

    IEを以下の設定にすることで、エラーを回避できます。

    「セキュリティ」タブ→「レベルのカスタマイズ」ボタン→リストの「その他」→「サーバーにファイルをアップロードするときにローカルディレクトリのパスを含める」のラジオボタンで「無効にする」を選択。

  • タブレットでの作成操作の制約

    タブレット端末で、データベースの項目、部品の並べ替えの操作がうまく行えません。どうすればよいですか？

    タブレット端末では、ピンチ操作（2本の指でつまむ操作）によって画面を拡大または縮小した場合、項目や部品の並び替え操作を正常に行えないことがあります。
    このような場合は、ブラウザの表示拡大率を100％に変更することで正常に動作します。

  • iPhone、iPadにおける一覧画面の表示制約

    iPhone、iPadで一覧画面の横スクロールバーが表示されません。どのように操作すればよいですか？

    iPhone、iPadでは一覧表示画面の横スクロールバーが表示されない制約があります。通常、横スクロールバーが表示されると思われるあたりを操作することで、スクロールできます。
