  • IPアドレスによるログイン制限

    使用するパソコンのIPアドレスによって、ログイン制限することはできますか？

    イットbuilderでは、特定のIPアドレス以外の端末はイットbuilderにアクセス（ログイン）できないよう、アプリごとに制限することができます。
    この機能を利用すれば、アンケートアプリは社外の不特定多数の方も使用できるようにし、社員だけが使用するアプリはIPアドレス制限で社外第三者の使用をブロックする、などの制御が可能です。

  • プルダウン項目の絞り込み

    択一選択プルダウンで、選択候補が多い場合にマウス操作で対象のものを探すのが面倒なのですが、何かよい方法はありませんか？

    択一選択プルダウンには、検索オプションがあります。
    これを利用することで、選択対象の文字列の一部を指定し、選択候補を絞り込むことができます。

  • 複数データベースの1画面表示

    複数のデータベースの情報を1画面に表示できますか？

    イットbuilderでは「1対N形式データ表示」が可能です。
    通常、1画面には1つのデータベースのデータを表示するのに対し、「1対N形式データ表示」では、あるデータベースの1件のデータとともに、これに関連する他のデータベースの複数件（N件）のデータを1画面に表示するものです。
    たとえば、従業員台帳アプリにおいて、ある従業員の氏名、入社年月日などの従業員マスタの情報（1件）とともに、この従業員が保有する複数（N件）の資格情報を資格マスタから抽出して1画面に表示するなどのアプリを作成することができます。
